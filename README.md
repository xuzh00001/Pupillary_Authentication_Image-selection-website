# Image Selection Web App

This is a static web page for letting participants choose one favorite color image from each of 5 categories, then memorize the grayscale versions of the 5 selected images.

## File Locations

- Entry page: [index.html](C:\Users\xuening\Documents\Playground\image-selector-web\index.html)
- Image assets: `C:\Users\xuening\Documents\Playground\image-selector-web\assets`

## How to Use

1. Open `index.html`
2. Enter a participant ID if needed
3. Browse each category and select one image per category
4. In the final phase, ask the participant to memorize the 5 grayscale images
5. If you want to save the choices, click `Download Results`

## Current Features

- Automatically loads 5 categories with 20 images each
- Automatically pairs color and grayscale images by index
- Supports previous/next browsing
- Supports one final selection per category
- Shows a final grayscale summary page
- Exports the result as JSON
